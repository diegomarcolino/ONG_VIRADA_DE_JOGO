# 🎲 ONG Virada de Jogo

> Plataforma digital institucional desenvolvida para oferecer suporte, acolhimento e orientação a pessoas afetadas pelo vício em jogos e apostas eletrônicas (bets), além de prestar apoio aos seus familiares.

---

## 📌 Sobre o Projeto
A **ONG Virada de Jogo** é um projeto web desenvolvido para centralizar ações de apoio social, orientação sobre autoexclusão de plataformas de apostas, suporte jurídico e cadastramento de voluntários.

Este repositório contém o código-fonte da interface da aplicação, construída com foco em acessibilidade, navegação intuitiva e design acolhedor.

---

## 🚀 Funcionalidades e Páginas
 - ## 🏠 Página Inicial (index.html)
 - Botão de atendimento imediato via WhatsApp.
 - Informações sobre sinais de alerta e conscientização dos riscos associados às apostas.
 - Divulgação de informações e horários das reuniões presenciais no MASP.
 - ## 🎯 Projetos (projetos.html)
 - Desconecta Bet: orientação técnica para bloqueio de sites e aplicativos de apostas.
 - Reorganização Financeira: suporte jurídico e auxílio na renegociação de dívidas.
 - Acolhimento Familiar: apoio e orientação para familiares de pessoas afetadas pela dependência em jogos.
 - Direcionamento para acompanhamento remoto por meio das redes sociais.
 - ## 🤝 Como Ajudar (ajuda.html)
 - Central de informações sobre voluntariado.
 - Divulgação de dados bancários e chave PIX institucional para doações.
 - ## 📝 Cadastro (cadastro.html)
 - Formulário de inscrição para novos voluntários e parceiros.
 - Validação de campos e interatividade implementadas com JavaScript no lado do cliente.

--- 

## 💻 Tecnologias Utilizadas
**HTML5**: estruturação semântica das páginas.
**CSS3**: criação de layouts responsivos, gradientes e estilos visuais.
**JavaScript (ES6+)**: validação de formulários e implementação das interações da interface.

## ⚙️ Como Executar o Projeto
> Como o projeto utiliza HTML5, CSS3 e JavaScript no lado do cliente, não é necessário instalar o Node.js, utilizar gerenciadores de pacotes como npm ou Yarn, nem configurar um backend para visualizar a interface.

---

## 📌 Pré-requisitos
Um navegador atualizado, como Google Chrome, Mozilla Firefox, Microsoft Edge, Brave ou Safari.
Opcionalmente, o Visual Studio Code (VS Code) com a extensão Live Server.

---
## 🚀 Passo a Passo
#### Opção 1: Executar com VS Code e Live Server (recomendado)
Obtenha os arquivos do projeto.
 - Clone o repositório utilizando o terminal:
  
   git clone https://github.com/Matheus-Aureliano/ONG_VIRADA_DE_JOGO.git
   
   
- Como alternativa, acesse o repositório no GitHub, baixe os arquivos em formato ZIP e extraia-os em seu computador.

#### 2: Abra o projeto no VS Code.
 - Acesse Arquivo → Abrir Pasta... e selecione a pasta do projeto.

- Inicie o servidor local.
 Na barra lateral do VS Code, clique com o botão direito no arquivo index.html e selecione Open with Live Server.

- Acesse o site.
 O projeto será aberto automaticamente no navegador, geralmente no endereço: http://127.0.0.1:5500
 - A porta poderá variar conforme a configuração do Live Server.

## Opção 2: Abrir diretamente no navegador
 - Baixe o repositório pelo GitHub ou clone-o utilizando o comando apresentado anteriormente.
 - Extraia os arquivos, caso tenha baixado o ZIP.
 - Localize o arquivo index.html na pasta do projeto.
 - Dê um duplo clique no arquivo para abri-lo no navegador padrão.
 #### Observação: a abertura direta funciona para páginas estáticas que não dependam de recursos específicos de um servidor local. Caso ocorram problemas com caminhos de arquivos ou funcionalidades do navegador, utilize o Live Server.

## 🎓 Contexto Acadêmico
Este projeto foi desenvolvido como parte de um portfólio prático de desenvolvimento front-end, aplicando conceitos de estruturação de páginas web, HTML semântico, estilização com CSS e interatividade com JavaScript.

O objetivo é demonstrar a aplicação desses conhecimentos na criação de uma plataforma digital voltada à conscientização, ao acolhimento e ao apoio social de pessoas afetadas pelos problemas relacionados às apostas eletrônicas

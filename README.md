# ONG Virada de Jogo

> Plataforma digital institucional desenvolvida para oferecer suporte, acolhimento e orientação a pessoas afetadas pelo vício em jogos e apostas eletrônicas, além de prestar apoio aos seus familiares.

---

## 📌 Sobre o Projeto

A **ONG Virada de Jogo** é um projeto web desenvolvido com o objetivo de centralizar ações de apoio social, orientação sobre autoexclusão de plataformas de apostas, suporte jurídico e cadastro de voluntários.

O projeto busca oferecer informações de forma acessível, por meio de uma interface intuitiva, organizada e acolhedora.

---

## 🚀 Funcionalidades e Páginas

### 🏠 Página Inicial (index.html)

- Apresentação institucional da ONG.
- Botão de atendimento via WhatsApp.
- Informações sobre sinais de alerta relacionados às apostas.
- Divulgação de reuniões presenciais e ações de conscientização.

### 🎯 Projetos (projetos.html)

- **Desconecta Bet:** orientação para bloqueio de sites e aplicativos de apostas.
- **Reorganização Financeira:** informações sobre suporte jurídico e renegociação de dívidas.
- **Acolhimento Familiar:** apoio e orientação aos familiares.
- Divulgação dos projetos e formas de contato.

### 🤝 Como Ajudar (ajuda.html)

- Informações sobre voluntariado.
- Divulgação de formas de contribuição.
- Informações para realização de doações via PIX.

### 📝 Cadastro (cadastro.html)

- Formulário de inscrição para novos voluntários e parceiros.
- Validação de campos.
- Interatividade implementada com JavaScript.

---

## 💻 Tecnologias Utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, layouts e responsividade.
- **JavaScript (ES6+):** validação de formulários e interações.

## ⚙️ Como executar o projeto

O projeto utiliza HTML, CSS e JavaScript, não sendo necessária a instalação de dependências ou configuração de um backend para visualizar as páginas.

### 📌 Pré-requisitos

- Navegador atualizado (Google Chrome, Firefox, Edge ou Safari).
- Visual Studio Code (opcional).
- Extensão Live Server (opcional).

### ## 🚀 Passo a Passo

### Opção 1: Executar com VS Code e Live Server (recomendado)

Obtenha os arquivos do projeto.

- **Clone o repositório utilizando o terminal:**

  ```bash
  git clone https://github.com/diegomarcolino/ONG_VIRADA_DE_JOGO.git
  ```

- Como alternativa, acesse o repositório no GitHub, baixe os arquivos em formato ZIP e extraia-os em seu computador.

**Abra o projeto no VS Code:**

- Acesse **Arquivo → Abrir Pasta...** e selecione a pasta do projeto.
- Inicie o servidor local. Na barra lateral do VS Code, clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.
- Acesse o site. O projeto será aberto automaticamente no navegador, geralmente no endereço `http://127.0.0.1:5500`.
- A porta poderá variar de acordo com a configuração do Live Server.

### Opção 2: Abrir diretamente no navegador

- Baixe o repositório pelo GitHub ou clone-o utilizando o comando apresentado anteriormente.
- Extraia os arquivos, caso tenha baixado o ZIP.
- Localize o arquivo `index.html` na pasta do projeto.
- Dê um clique duplo no arquivo para abri-lo no navegador padrão.

**Observação:** a abertura direta funciona para páginas estáticas que não dependem de recursos específicos de um servidor local. Caso ocorram problemas com caminhos de arquivos ou funcionalidades do navegador, utilize o Live Server.

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como parte de um trabalho acadêmico de desenvolvimento web, colocando em prática conhecimentos de HTML, CSS e JavaScript.

O objetivo é demonstrar a aplicação dos conceitos de desenvolvimento front-end na criação de uma plataforma digital voltada à conscientização, ao acolhimento e ao apoio social de pessoas afetadas pelos problemas relacionados às apostas eletrônicas.
